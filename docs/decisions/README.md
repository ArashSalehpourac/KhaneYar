# Decision Log

This directory stores significant product, project, commercial, UX, and delivery decisions for KhaneYar.

Each decision record should include:

- Decision ID
- Date
- Related ClickUp task
- Context/problem
- Options considered
- Decision
- Rationale
- Consequences/trade-offs
- Evidence links
- Revisit trigger, if any

Do not use this directory for architecture decisions; use `docs/adr/` for those.
