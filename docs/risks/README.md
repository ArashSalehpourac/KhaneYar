# Risk Register

This directory stores KhaneYar project, product, technical, privacy, commercial, and delivery risk records.

Each risk record should include:

- Risk ID
- Date identified
- Related ClickUp task/phase
- Description
- Probability
- Impact
- Exposure/severity
- Mitigation
- Trigger/early warning
- Owner
- Status
- Evidence links

Do not mark a risk closed without evidence that the exposure has been removed or accepted.
