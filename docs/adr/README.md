# Architecture Decision Records (ADRs)

This directory stores Architecture Decision Records for KhaneYar.

Use one file per significant technical decision. A record should contain:

- ADR ID and title
- Status: Proposed / Accepted / Superseded / Deprecated
- Date
- Related ClickUp task
- Context
- Decision drivers
- Options considered
- Decision
- Consequences
- Risks
- Evidence or experiment links

Do not create ADRs before the underlying architectural question exists. Phase 0 should only establish the mechanism.
